Every method here is reached through the `Steam` facade
(`Fkrzski\LaravelSteamApiSdk\Facades\Steam`): an endpoint on the resource for its Steam
interface, the rest on the facade itself. Endpoints take a
[`SteamId`](/laravel-steam-api-sdk/guide#the-steamid-value-object) wherever they
identify a user and return readonly DTOs from the underlying SDK, documented in
[Data objects](/php-steam-api-sdk/dto-reference).

Badges list what an endpoint raises on its own. On top of that, any call can raise
`SteamRateLimitException`, `SteamConnectionException`, `UnreadableResponseException` or
`SteamApiException` itself, `ProfileNotPublicException` for a `401` or `403` the endpoint gives no
meaning of its own, and `InvalidSteamConfigException` for a config value the bridge cannot use. A
request that needs the key can raise `ApiKeyNotConfiguredException`
and `InvalidApiKeyException`; the `apps()`, `news()` and `webApi()` endpoints, `currentPlayers()`,
`globalAchievements()` and `newsFeed()` need none. A DTO Steam's answer cannot fill fails the call
with whatever building it raised — see [Exceptions](/laravel-steam-api-sdk/guide#exceptions).

## Resources

The base SDK groups its endpoints into one resource per Steam interface, and the facade
hands each back as the connector builds it — `AppsResource`, `NewsResource`,
`PlayersResource`, `StatsResource`, `UsersResource` and `WebApiResource` from
`Fkrzski\SteamApiSdk\Http\Resources`.

```text frame="none"
Steam::apps(): AppsResource
Steam::news(): NewsResource
Steam::players(): PlayersResource
Steam::stats(): StatsResource
Steam::users(): UsersResource
Steam::webApi(): WebApiResource
```

| Resource | Steam interface | Methods |
| --- | --- | --- |
| `Steam::apps()` | `ISteamApps` | `sdrConfig()`, `serversAtAddress()`, `upToDateCheck()` |
| `Steam::news()` | `ISteamNews` | `appNews()` |
| `Steam::players()` | `IPlayerService` | `badges()`, `communityBadgeProgress()`, `ownedGames()`, `recentlyPlayedGames()`, `steamLevel()` |
| `Steam::stats()` | `ISteamUserStats` | `achievements()`, `currentPlayers()`, `globalAchievements()`, `schema()`, `userStats()` |
| `Steam::users()` | `ISteamUser` | `bans()`, `friends()`, `groups()`, `resolveVanityUrl()`, `summaries()` |
| `Steam::webApi()` | `ISteamWebAPIUtil` | `serverTime()`, `supportedApis()` |

A resource sends through the same scoped connector the facade uses, so
[`fake()`](#fake) covers one you reached before installing the mock.

## Endpoints

Alphabetical, each under its resource. `newsFeed()` is the one the bridge adds on the facade
itself.

### `achievements()`

```text frame="none"
Steam::stats()->achievements(SteamId $steamId, int $appId, ?Language $language = null): PlayerAchievements
```

<Badge text="throws StatsUnavailableException" variant="danger" size="small" />
<Badge text="throws ProfileNotPublicException" variant="danger" size="small" />

Returns a player's achievements for one game, each with its unlock state and time.
`language` localises the achievement name and description. Steam answers a private
profile and an app without achievements identically, so a `400` becomes
`StatsUnavailableException` either way; a `401` is the hidden-profile case.

```php
use Fkrzski\SteamApiSdk\Enums\Language;

$result = Steam::stats()->achievements($steamId, appId: 381210, language: Language::English);

foreach ($result->achievements as $achievement) {
    echo $achievement->apiName, ' — ', $achievement->achieved ? 'unlocked' : 'locked', PHP_EOL;
}
```

### `appNews()`

```text frame="none"
Steam::news()->appNews(
    int $appId,
    ?int $count = null,
    ?int $maxLength = null,
    ?DateTimeInterface $endDate = null,
    list<string> $feeds = [],
    list<string> $tags = [],
): AppNews
```

<Badge text="throws AppNewsUnavailableException" variant="danger" size="small" />

Returns an app's news, newest first: Steam's own announcements beside the blog and press feeds
it collects. `count` caps the page, 20 when omitted, while `total` counts every post the filter
matches. `feeds` and `tags` filter by feed name and tag, and no key goes out. An app ID Steam
does not know raises, and so do some it does, such as Spacewar, because Steam answers the two
alike.

```php
$news = Steam::news()->appNews(appId: 440, count: 5, feeds: ['steam_community_announcements']);

foreach ($news->items as $item) {
    echo $item->publishedAt->format('Y-m-d'), ' — ', $item->title, PHP_EOL;
}
```

<Aside type="caution" title="What Steam does with the arguments">
Without `maxLength`, or with `0`, each body comes in its feed's own markup, BBCode included;
any positive value flattens it, even when it fits, and cuts a longer one to an excerpt. An
unknown feed name is ignored, so a misspelt one returns every feed. `endDate` is inclusive, so
paging by the last post's date repeats it — [`newsFeed()`](#newsfeed) handles that.
</Aside>

### `badges()`

```text frame="none"
Steam::players()->badges(SteamId $steamId): PlayerBadges
```

<Badge text="throws ProfileNotPublicException" variant="danger" size="small" />

Returns every badge a player has earned, with the XP and level they add up to.
Trading-card badges name the app they came from; event and milestone badges leave
`appId` null. An account with no badges answers with level `0` rather than raising.

```php
$badges = Steam::players()->badges($steamId);

echo $badges->playerLevel, ' — ', $badges->xpNeededToLevelUp, ' XP to go', PHP_EOL;

foreach ($badges->badges as $badge) {
    echo $badge->badgeId, ' level ', $badge->level, PHP_EOL;
}
```

### `bans()`

```text frame="none"
Steam::users()->bans(list<SteamId> $steamIds, int $concurrency = 5): list<PlayerBan>
```

<Badge text="throws InvalidArgumentException" variant="danger" size="small" />

Fetches community, VAC, game and economy bans for any number of players. Ban records are public,
so a hidden profile still returns a row. Up to 100 IDs go out as one request, and a longer list as
requests of 100, `concurrency` at a time, each sent once — see
[More than 100 Steam IDs](/php-steam-api-sdk/guide#more-than-100-steam-ids). An empty list or a
`concurrency` under 1 raises `InvalidArgumentException` before anything is sent, and the rows come
back in no particular order, so key them by Steam ID.

```php
$bans = Steam::users()->bans([$steamId]);

foreach ($bans as $ban) {
    echo $ban->steamId->value, ' — ', $ban->isVacBanned ? 'VAC banned' : 'clean', PHP_EOL;
}
```

### `communityBadgeProgress()`

```text frame="none"
Steam::players()->communityBadgeProgress(SteamId $steamId): list<CommunityBadgeQuest>
```

<Badge text="throws ProfileNotPublicException" variant="danger" size="small" />

Returns the quests behind the Steam community badge, each with the flag saying whether
the account finished it. Steam publishes no names for them, so `questId` stays opaque.

```php
foreach (Steam::players()->communityBadgeProgress($steamId) as $quest) {
    echo $quest->questId, $quest->completed ? ' — done' : ' — pending', PHP_EOL;
}
```

### `currentPlayers()`

```text frame="none"
Steam::stats()->currentPlayers(int $appId): int
```

<Badge text="throws AppNotFoundException" variant="danger" size="small" />

Returns how many players are in a game right now, as a plain `int` rather than a DTO.
Steam serves it without a key; an app ID it does not know answers `404` and raises.

```php
$playing = Steam::stats()->currentPlayers(appId: 381210);
```

### `friends()`

```text frame="none"
Steam::users()->friends(SteamId $steamId, ?FriendRelationship $relationship = null): list<Friend>
```

<Badge text="throws ProfileNotPublicException" variant="danger" size="small" />

Lists a player's friends, each with the relationship and the date it started.
`relationship` narrows the result; omit it to let Steam decide.

```php
use Fkrzski\SteamApiSdk\Enums\FriendRelationship;

$friends = Steam::users()->friends($steamId, FriendRelationship::Friend);

foreach ($friends as $friend) {
    echo $friend->steamId->value, ' — since ', $friend->friendSince->format('Y-m-d'), PHP_EOL;
}
```

<Aside type="caution" title="A private friend list is a 401">
Unlike `ownedGames()`, this endpoint refuses the request rather than returning an
empty payload — a hidden list never reaches you as an empty result.
</Aside>

### `globalAchievements()`

```text frame="none"
Steam::stats()->globalAchievements(int $gameId): list<GlobalAchievement>
```

<Badge text="throws StatsUnavailableException" variant="danger" size="small" />

Returns the share of the player base holding each achievement in a game. The argument
keeps the name the base SDK gives it — Valve spells this one endpoint's identifier
`gameid`, though the value is an ordinary app ID. No key goes out here either.

```php
foreach (Steam::stats()->globalAchievements(gameId: 381210) as $achievement) {
    echo $achievement->apiName, ' — ', round($achievement->percent, 2), '%', PHP_EOL;
}
```

<Aside type="caution" title="One 403 covers two causes">
Steam refuses a game carrying no achievements and a game ID it does not know
identically, so `StatsUnavailableException` says nothing about which. It is never about
your key: this endpoint sends none.
</Aside>

### `groups()`

```text frame="none"
Steam::users()->groups(SteamId $steamId): list<UserGroup>
```

<Badge text="throws ProfileNotPublicException" variant="danger" size="small" />

Lists the community groups a player belongs to, each as a `UserGroup` carrying its
`gid`; empty when the player is in no group. Steam returns group IDs only — resolve
names through the community API yourself.

```php
$groups = Steam::users()->groups($steamId);

foreach ($groups as $group) {
    echo $group->gid, PHP_EOL;
}
```

### `newsFeed()`

```text frame="none"
Steam::newsFeed(
    int $appId,
    int $perPage = 20,
    ?int $maxLength = null,
    ?DateTimeInterface $endDate = null,
    list<string> $feeds = [],
    list<string> $tags = [],
): LazyCollection<int, NewsItem>
```

<p><Badge text="throws AppNewsUnavailableException" variant="danger" size="small" />{' '}<Badge text="throws InvalidArgumentException" variant="danger" size="small" /></p>

Walks an app's news lazily, newest first, sending one `appNews()` request per page of
`perPage` only as the collection is read, so `->take(30)` stops once it has 30. Every page
after the first asks for posts up to the last one's date and skips by ID what it already yielded.
A `perPage` below 2 raises `InvalidArgumentException`.

```php
foreach (Steam::newsFeed(appId: 440)->take(30) as $item) {
    echo $item->title, PHP_EOL;
}
```

<Aside type="caution" title="Posts sharing a second end the feed">
The feed ends on a page holding all that remains or bringing nothing new. A page can bring
nothing new when `perPage` or more posts share one second, so raise `perPage` for an app that
publishes in bursts.
</Aside>

### `ownedGames()`

```text frame="none"
Steam::players()->ownedGames(
    SteamId $steamId,
    list<int> $appIdsFilter = [],
    bool $includeAppInfo = false,
    bool $includePlayedFreeGames = false,
): list<OwnedGame>
```

<Badge text="throws ProfileNotPublicException" variant="danger" size="small" />

Lists the games a player owns. `appIdsFilter` narrows the result to specific app
IDs, `includeAppInfo` adds names and icons, `includePlayedFreeGames` includes free
games the player has launched.

```php
$library = Steam::players()->ownedGames(
    steamId: $steamId,
    appIdsFilter: [381210],
    includeAppInfo: true,
);
```

### `recentlyPlayedGames()`

```text frame="none"
Steam::players()->recentlyPlayedGames(SteamId $steamId, ?int $count = null): RecentlyPlayedGames
```

<Badge text="throws ProfileNotPublicException" variant="danger" size="small" />

Returns what a player launched in the last two weeks. `count` caps how many games come
back, while `totalCount` stays Steam's own figure for the window — that is how you tell a
capped list from a complete one. A player who launched nothing comes back as
`totalCount: 0`, not an exception.

```php "count: 5"
$recent = Steam::players()->recentlyPlayedGames($steamId, count: 5);

foreach ($recent->games as $game) {
    echo $game->name, ' — ', $game->playtimeTwoWeeks, ' min', PHP_EOL;
}
```

### `resolveVanityUrl()`

```text frame="none"
Steam::users()->resolveVanityUrl(string $vanityName): SteamId
```

<Badge text="throws SteamUserNotFoundException" variant="danger" size="small" />

Resolves a vanity slug — the `<name>` in `steamcommunity.com/id/<name>` — to a
`SteamId`.

```php
$steamId = Steam::users()->resolveVanityUrl('gabelogannewell');
```

### `schema()`

```text frame="none"
Steam::stats()->schema(int $appId, ?Language $language = null): GameSchema
```

<Badge text="throws AppNotFoundException" variant="danger" size="small" />

Returns every stat and achievement a game publishes, with `language` localising the
achievement names and descriptions. An app that publishes no schema comes back as an
empty `GameSchema` — a null `gameName` and two empty lists — rather than raising; only
an app ID Steam does not know does that.

```php
$schema = Steam::stats()->schema(appId: 381210);

foreach ($schema->achievements as $achievement) {
    echo $achievement->apiName, ' — ', $achievement->hidden ? 'hidden' : $achievement->name, PHP_EOL;
}
```

### `sdrConfig()`

```text frame="none"
Steam::apps()->sdrConfig(int $appId): SdrConfig
```

<Badge text="throws AppNotFoundException" variant="danger" size="small" />

Returns the Steam Datagram Relay network a game connects through, its points of presence
keyed by code. A game without a network of its own gets Valve's default one. Steam serves
it without a key, and answers an app ID it does not know with a `500` that raises at once,
however many tries the connector allows.

```php
$config = Steam::apps()->sdrConfig(appId: 730);

foreach ($config->pointsOfPresence['waw']->relays as $relay) {
    echo $relay->ipv4, ':', $relay->minPort, '-', $relay->maxPort, PHP_EOL;
}
```

### `serversAtAddress()`

```text frame="none"
Steam::apps()->serversAtAddress(string $address): list<GameServer>
```

<Badge text="throws InvalidServerAddressException" variant="danger" size="small" />

Lists the game servers Steam knows at an IPv4 address, or only the one behind
`ip:queryport`. An address with no servers returns an empty list, and no key goes out.

```php
foreach (Steam::apps()->serversAtAddress('108.181.62.21') as $server) {
    echo $server->address, ' runs app ', $server->appId, PHP_EOL;
}
```

<Aside type="caution" title="The port is the query port">
The game port or the SourceTV port finds nothing, and an IPv6 address or a hostname raises.
Steam refuses to look some addresses up at all, with a "once per minute" message that
arrives as `SteamApiException` itself.
</Aside>

### `serverTime()`

```text frame="none"
Steam::webApi()->serverTime(): DateTimeImmutable
```

Returns Steam's clock in UTC, as a `DateTimeImmutable` rather than a DTO. Steam serves it
anonymously, so no key goes out, even with one configured.

```php
$skew = Steam::webApi()->serverTime()->getTimestamp() - time();
```

### `steamLevel()`

```text frame="none"
Steam::players()->steamLevel(SteamId $steamId): int
```

<Badge text="throws ProfileNotPublicException" variant="danger" size="small" />

Returns a player's community level as a plain `int` rather than a DTO. Hiding game
details leaves the level readable — only a profile Steam withholds altogether raises.

```php
$level = Steam::players()->steamLevel($steamId);
```

### `summaries()`

```text frame="none"
Steam::users()->summaries(list<SteamId> $steamIds, int $concurrency = 5): list<PlayerSummary>
```

<Badge text="throws InvalidArgumentException" variant="danger" size="small" />

Fetches public profile summaries for any number of players, split and sent like
[`bans()`](#bans), with the same `InvalidArgumentException` and in no particular order either. A
hidden or friends-only profile comes back
[stripped](/php-steam-api-sdk/dto-reference#playersummary) rather than refused.

```php
$summaries = Steam::users()->summaries([$steamId]);

foreach ($summaries as $summary) {
    echo $summary->personaName, ' — ', $summary->profileUrl, PHP_EOL;
}
```

### `supportedApis()`

```text frame="none"
Steam::webApi()->supportedApis(): list<WebApiInterface>
```

<Badge text="throws InvalidApiKeyException" variant="danger" size="small" />

Lists every Web API method Steam lets the caller see, grouped by interface. The key goes along
when one is configured and adds the methods it can call, while without one Steam answers with
the anonymous list. A key Steam rejects comes back as a JSON `403` rather than its usual HTML
page, and still raises.

```php
foreach (Steam::webApi()->supportedApis() as $interface) {
    foreach ($interface->methods as $method) {
        echo $interface->name, '/', $method->name, '/v', $method->version, PHP_EOL;
    }
}
```

### `upToDateCheck()`

```text frame="none"
Steam::apps()->upToDateCheck(int $appId, int $version): AppVersionCheck
```

<Badge text="throws AppVersionUnavailableException" variant="danger" size="small" />

Tells a game server whether its build is still the one Steam accepts, and which version to
update to if not. Steam serves it without a key, and answers an app ID it does not know
exactly like a game publishing no server version, so both raise. App ID `0` gets a `400`,
which arrives as `SteamApiException` itself.

```php
$check = Steam::apps()->upToDateCheck(appId: 440, version: $installedVersion);

if (! $check->isUpToDate) {
    echo 'Update to ', $check->requiredVersion, ': ', $check->message, PHP_EOL;
}
```

### `userStats()`

```text frame="none"
Steam::stats()->userStats(SteamId $steamId, int $appId): UserStats
```

<Badge text="throws ProfileNotPublicException" variant="danger" size="small" />

Returns a player's stats and achievement flags for one game, by API name; their display names
come from [`schema()`](#schema). It takes no `language`, since Steam answers the same payload with
one and without.

```php
$stats = Steam::stats()->userStats($steamId, appId: 381210);

foreach ($stats->stats as $stat) {
    echo $stat->name, ' = ', $stat->value, PHP_EOL;
}
```

## Low-level helpers

### `connector()`

```text frame="none"
Steam::connector(): SteamConnector
```

Returns the underlying `Fkrzski\SteamApiSdk\SteamConnector` for the current
request. Use it for Saloon features the facade does not expose.

<Aside type="caution">
The binding is **scoped** — do not hold the instance past the request that
resolved it. See [The connector binding](/laravel-steam-api-sdk/configuration#the-connector-binding).
</Aside>

### `fake()`

```text frame="none"
Steam::fake(
    array<array-key, MockResponse|Fixture|callable(PendingRequest): mixed> $responses = [],
): SteamFake
```

<Badge text="throws FakeOutsideTestsException" variant="danger" size="small" />

Attaches the base SDK's `Fkrzski\SteamApiSdk\Testing\SteamFake`, a Saloon `MockClient`, to the
connector and returns it, dropping the pause between retries. Refused unless the application
environment is `testing`. Its `apps()`, `news()`, `players()`, `stats()`, `users()` and `webApi()`
fake each endpoint by name and hand the mock back — see
[Faking responses](/laravel-steam-api-sdk/testing#faking-responses). The assertions and
readers sit on the facade too, under [Test assertions](#test-assertions) and
[Recorded traffic](#recorded-traffic).

### `pool()`

```text frame="none"
Steam::pool(
    iterable<Request>|callable $requests = [],
    int|callable $concurrency = 5,
    ?callable $responseHandler = null,
    ?callable $exceptionHandler = null,
): Saloon\Http\Pool
```

Builds a Saloon `Pool` for sending Steam requests concurrently. See
[Concurrent requests](/laravel-steam-api-sdk/guide#concurrent-requests).

### `send()`

```text frame="none"
Steam::send(Saloon\Http\Request $request): Saloon\Http\Response
```

Sends any Saloon `Request` through the shared connector and returns the raw
`Response` — the escape hatch for requests the resources don't cover. Decode it with
`->dto()` yourself; whatever the request raises reaches you unchanged.

## Events

The bridge dispatches three events for Steam traffic, from `Fkrzski\LaravelSteamApiSdk\Events`,
each with public readonly properties. [Events](/laravel-steam-api-sdk/events) covers when each
fires.

### `SteamRequestFailed`

```text frame="none"
SteamRequestFailed(Throwable $exception)
```

The exception the caller gets: an SDK one after the retries, whatever building the DTO raised, or
whatever a listener threw.

### `SteamRequestSending`

```text frame="none"
SteamRequestSending(string $method, array<string, mixed> $query, int $attempt)
```

`method` is the Steam path, such as `ISteamUser/GetPlayerSummaries/v2`, and `query` what Steam
receives, without the API key. `attempt` is `1`, then `2` for the first retry.

### `SteamResponseReceived`

```text frame="none"
SteamResponseReceived(
    string $method,
    array<string, mixed> $query,
    int $attempt,
    int $status,
    float $duration,
)
```

The same three as `SteamRequestSending`, plus the HTTP `status` and the `duration` in seconds
from sending to Steam's answer.

## Test assertions

Saloon's `MockClient` assertions, proxied onto the facade so a test never has to
hold the mock in a variable. See [Asserting](/laravel-steam-api-sdk/testing#asserting).

<Aside type="caution" title="Fake first">
Every assertion here reads the mock attached by [`fake()`](#fake). Without one
there is nothing to assert against, so they raise `FakeNotInstalledException`
rather than passing.
</Aside>

### `assertNothingSent()`

```text frame="none"
Steam::assertNothingSent(): void
```

Asserts that the fake recorded no requests at all.

### `assertNotSent()`

```text frame="none"
Steam::assertNotSent(string|callable $request): void
```

Asserts that no request matching the class name, URL pattern or closure was sent.

### `assertSent()`

```text frame="none"
Steam::assertSent(string|callable $value): void
```

Asserts that a request matching the class name, URL pattern or closure was sent.
The closure receives the request and its response, so it can assert on query
parameters, headers or the payload that came back.

```php
Steam::assertSent(
    fn (GetPlayerBansRequest $request): bool => count($request->steamIds) === 2,
);
```

### `assertSentCount()`

```text frame="none"
Steam::assertSentCount(int $count, ?string $requestClass = null): void
```

Asserts how many requests were sent. `requestClass` narrows the count to a single
request; omit it to count everything the fake recorded.

### `assertSentInOrder()`

```text frame="none"
Steam::assertSentInOrder(array<Closure|class-string<Request>|string> $callbacks): void
```

Asserts that these requests were sent, in this order, and nothing else with them. A closure or a
URL pattern has to match its position, while a class name Saloon also finds anywhere else in the
history, so for those only the count is strict.

## Recorded traffic

Saloon's `MockClient` readers, proxied onto the facade for tests that inspect the
traffic rather than assert on it. See
[Recorded traffic](/laravel-steam-api-sdk/testing#recorded-traffic).

<Aside type="caution" title="Fake first">
Every reader here reads the mock attached by [`fake()`](#fake). Without one there
is no history at all, so they raise `FakeNotInstalledException` rather than
returning an empty one.
</Aside>

### `lastRequest()`

```text frame="none"
Steam::lastRequest(): ?Saloon\Http\Request
```

The last request the fake handled, or `null` when nothing was sent.

### `lastResponse()`

```text frame="none"
Steam::lastResponse(): ?Saloon\Http\Response
```

The last response the fake returned, or `null` when nothing was sent.

### `recorded()`

```text frame="none"
Steam::recorded(): array<Saloon\Http\Response>
```

Every response the fake recorded, in the order they came back. Reach the request
behind one through `$response->getPendingRequest()->getRequest()`.
