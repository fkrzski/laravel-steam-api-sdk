import { Aside, Badge } from '@astrojs/starlight/components';

Every method here lives on the `Steam` facade
(`Fkrzski\LaravelSteamApiSdk\Facades\Steam`). The request helpers take a
[`SteamId`](/laravel-steam-api-sdk/guide#the-steamid-value-object) wherever they
identify a user and return readonly DTOs from the underlying SDK, documented in
[Data objects](/php-steam-api-sdk/dto-reference).

<Aside title="Three exceptions every request can raise">
`SteamApiKeyMissingException` (no key configured), `InvalidApiKeyException` (Steam
rejected it) and `SteamRateLimitException` (daily quota spent). They are listed
per method only where a helper raises them on its own. Every exception below
extends `SteamApiException`.
</Aside>

## Request helpers

### `achievements()`

```text frame="none"
Steam::achievements(SteamId $steamId, int $appId, ?Language $language = null): PlayerAchievements
```

<Badge text="throws StatsUnavailableException" variant="danger" size="small" />
<Badge text="throws ProfileNotPublicException" variant="danger" size="small" />

Returns a player's achievements for one game, each with its unlock state and time.
`language` localises the achievement name and description. Steam answers a private
profile and an app without achievements identically, so a `400` becomes
`StatsUnavailableException` either way; a `401` is the hidden-profile case.

```php
use Fkrzski\SteamApiSdk\Enums\Language;

$result = Steam::achievements($steamId, appId: 381210, language: Language::English);

foreach ($result->achievements as $achievement) {
    echo $achievement->apiName, ' — ', $achievement->achieved ? 'unlocked' : 'locked', PHP_EOL;
}
```

### `badges()`

```text frame="none"
Steam::badges(SteamId $steamId): PlayerBadges
```

<Badge text="throws ProfileNotPublicException" variant="danger" size="small" />

Returns every badge a player has earned, with the XP and level they add up to.
Trading-card badges name the app they came from; event and milestone badges leave
`appId` null. An account with no badges answers with level `0` rather than raising.

```php
$badges = Steam::badges($steamId);

echo $badges->playerLevel, ' — ', $badges->xpNeededToLevelUp, ' XP to go', PHP_EOL;

foreach ($badges->badges as $badge) {
    echo $badge->badgeId, ' level ', $badge->level, PHP_EOL;
}
```

### `bans()`

```text frame="none"
Steam::bans(list<SteamId> $steamIds): list<PlayerBan>
```

<Badge text="throws TooManySteamIdsException" variant="danger" size="small" />
<Badge text="throws InvalidArgumentException" variant="danger" size="small" />

Fetches community, VAC, game and economy bans for **1 to 100** players. Ban records
are public, so a hidden profile still returns a row. An empty list of IDs raises
`InvalidArgumentException`, more than 100 raises `TooManySteamIdsException`.

```php
$bans = Steam::bans([$steamId]);

foreach ($bans as $ban) {
    echo $ban->steamId->value, ' — ', $ban->isVacBanned ? 'VAC banned' : 'clean', PHP_EOL;
}
```

### `communityBadgeProgress()`

```text frame="none"
Steam::communityBadgeProgress(SteamId $steamId): list<CommunityBadgeQuest>
```

<Badge text="throws ProfileNotPublicException" variant="danger" size="small" />

Returns the quests behind the Steam community badge, each with the flag saying whether
the account finished it. Steam publishes no names for them, so `questId` stays opaque.

```php
foreach (Steam::communityBadgeProgress($steamId) as $quest) {
    echo $quest->questId, $quest->completed ? ' — done' : ' — pending', PHP_EOL;
}
```

### `friends()`

```text frame="none"
Steam::friends(SteamId $steamId, ?FriendRelationship $relationship = null): list<Friend>
```

<Badge text="throws ProfileNotPublicException" variant="danger" size="small" />

Lists a player's friends, each with the relationship and the date it started.
`relationship` narrows the result; omit it to let Steam decide.

```php
use Fkrzski\SteamApiSdk\Enums\FriendRelationship;

$friends = Steam::friends($steamId, FriendRelationship::Friend);

foreach ($friends as $friend) {
    echo $friend->steamId->value, ' — since ', $friend->friendSince->format('Y-m-d'), PHP_EOL;
}
```

<Aside type="caution" title="A private friend list is a 401">
Unlike `ownedGames()`, this endpoint refuses the request rather than returning an
empty payload — a hidden list never reaches you as an empty result.
</Aside>

### `groups()`

```text frame="none"
Steam::groups(SteamId $steamId): list<UserGroup>
```

<Badge text="throws ProfileNotPublicException" variant="danger" size="small" />

Lists the community groups a player belongs to, each as a `UserGroup` carrying its
`gid`; empty when the player is in no group. Steam returns group IDs only — resolve
names through the community API yourself.

```php
$groups = Steam::groups($steamId);

foreach ($groups as $group) {
    echo $group->gid, PHP_EOL;
}
```

### `ownedGames()`

```text frame="none"
Steam::ownedGames(
    SteamId $steamId,
    list<int> $appIdsFilter = [],
    bool $includeAppInfo = false,
    bool $includePlayedFreeGames = false,
): list<OwnedGame>
```

<Badge text="throws ProfileNotPublicException" variant="danger" size="small" />

Lists the games a player owns. `appIdsFilter` narrows the result to specific app
IDs, `includeAppInfo` adds names and icons, `includePlayedFreeGames` includes free
games the player has launched.

```php
$library = Steam::ownedGames(
    steamId: $steamId,
    appIdsFilter: [381210],
    includeAppInfo: true,
);
```

### `recentlyPlayedGames()`

```text frame="none"
Steam::recentlyPlayedGames(SteamId $steamId, ?int $count = null): RecentlyPlayedGames
```

<Badge text="throws ProfileNotPublicException" variant="danger" size="small" />

Returns what a player launched in the last two weeks. `count` caps how many games come
back, while `totalCount` stays Steam's own figure for the window — that is how you tell a
capped list from a complete one. A player who launched nothing comes back as
`totalCount: 0`, not an exception.

```php "count: 5"
$recent = Steam::recentlyPlayedGames($steamId, count: 5);

foreach ($recent->games as $game) {
    echo $game->name, ' — ', $game->playtimeTwoWeeks, ' min', PHP_EOL;
}
```

### `resolveVanityUrl()`

```text frame="none"
Steam::resolveVanityUrl(string $vanityName): SteamId
```

<Badge text="throws SteamUserNotFoundException" variant="danger" size="small" />

Resolves a vanity slug — the `<name>` in `steamcommunity.com/id/<name>` — to a
`SteamId`.

```php
$steamId = Steam::resolveVanityUrl('gabelogannewell');
```

### `steamLevel()`

```text frame="none"
Steam::steamLevel(SteamId $steamId): int
```

<Badge text="throws ProfileNotPublicException" variant="danger" size="small" />

Returns a player's community level as a plain `int` rather than a DTO. Hiding game
details leaves the level readable — only a profile Steam withholds altogether raises.

```php
$level = Steam::steamLevel($steamId);
```

### `summaries()`

```text frame="none"
Steam::summaries(list<SteamId> $steamIds): list<PlayerSummary>
```

<Badge text="throws TooManySteamIdsException" variant="danger" size="small" />
<Badge text="throws InvalidArgumentException" variant="danger" size="small" />

Fetches public profile summaries for **1 to 100** players. Same bounds as
`bans()`: an empty list and more than 100 IDs each raise before a request is
sent.

```php
$summaries = Steam::summaries([$steamId]);

foreach ($summaries as $summary) {
    echo $summary->personaName, ' — ', $summary->profileUrl, PHP_EOL;
}
```

### `userStats()`

```text frame="none"
Steam::userStats(SteamId $steamId, int $appId, ?Language $language = null): UserStats
```

<Badge text="throws ProfileNotPublicException" variant="danger" size="small" />

Returns a player's stats and achievement flags for one game. `language` localises
achievement metadata, e.g. `Language::English`.

```php
$stats = Steam::userStats($steamId, appId: 381210);

foreach ($stats->stats as $stat) {
    echo $stat->name, ' = ', $stat->value, PHP_EOL;
}
```

## Resources

The base SDK groups its endpoints into one resource per Steam interface, and the facade
hands each back as the connector builds it — `PlayersResource`, `StatsResource` and
`UsersResource` from `Fkrzski\SteamApiSdk\Http\Resources`.

```text frame="none"
Steam::players(): PlayersResource
Steam::stats(): StatsResource
Steam::users(): UsersResource
```

Every request helper above is a shortcut for the resource method of the same name, with
the same signature, DTO and exceptions:

```php
Steam::summaries([$steamId]);           // the helper
Steam::users()->summaries([$steamId]);  // the resource behind it
```

| Resource | Steam interface | Methods |
| --- | --- | --- |
| `Steam::players()` | `IPlayerService` | `badges()`, `communityBadgeProgress()`, `ownedGames()`, `recentlyPlayedGames()`, `steamLevel()` |
| `Steam::stats()` | `ISteamUserStats` | `achievements()`, `userStats()` |
| `Steam::users()` | `ISteamUser` | `bans()`, `friends()`, `groups()`, `resolveVanityUrl()`, `summaries()` |

A resource sends through the same scoped connector the facade uses, so
[`fake()`](#fake) covers one you reached before installing the mock.

## Low-level helpers

### `connector()`

```text frame="none"
Steam::connector(): SteamConnector
```

Returns the underlying `Fkrzski\SteamApiSdk\SteamConnector` for the current
request. Use it for Saloon features the facade does not expose.

<Aside type="caution">
The binding is **scoped** — do not hold the instance past the request that
resolved it. See [The connector binding](/laravel-steam-api-sdk/configuration#the-connector-binding).
</Aside>

### `fake()`

```text frame="none"
Steam::fake(array<class-string, mixed> $responses = []): Saloon\Http\Faking\MockClient
```

<Badge text="throws FakeOutsideTestsException" variant="danger" size="small" />

Attaches a Saloon `MockClient` to the connector and returns it for assertions.
Refused unless the application environment is `testing`. The same assertions and
readers sit on the facade — see [Test assertions](#test-assertions) and
[Recorded traffic](#recorded-traffic) — so the return value is only worth keeping
for the rest of the mock's API. See
[Testing](/laravel-steam-api-sdk/testing).

### `pool()`

```text frame="none"
Steam::pool(
    iterable<Request>|callable $requests = [],
    int|callable $concurrency = 5,
    ?callable $responseHandler = null,
    ?callable $exceptionHandler = null,
): Saloon\Http\Pool
```

Builds a Saloon `Pool` for sending Steam requests concurrently. See
[Concurrent requests](/laravel-steam-api-sdk/guide#concurrent-requests).

### `send()`

```text frame="none"
Steam::send(Saloon\Http\Request $request): Saloon\Http\Response
```

Sends any Saloon `Request` through the shared connector and returns the raw
`Response` — the escape hatch for requests the helpers don't cover. Decode it with
`->dto()` yourself; whatever the request raises reaches you unchanged.

## Test assertions

Saloon's `MockClient` assertions, proxied onto the facade so a test never has to
hold the mock in a variable. See [Asserting](/laravel-steam-api-sdk/testing#asserting).

<Aside type="caution" title="Fake first">
Every assertion here reads the mock attached by [`fake()`](#fake). Without one
there is nothing to assert against, so they raise `FakeNotInstalledException`
rather than passing.
</Aside>

### `assertNothingSent()`

```text frame="none"
Steam::assertNothingSent(): void
```

Asserts that the fake recorded no requests at all.

### `assertNotSent()`

```text frame="none"
Steam::assertNotSent(string|callable $request): void
```

Asserts that no request matching the class name, URL pattern or closure was sent.

### `assertSent()`

```text frame="none"
Steam::assertSent(string|callable $value): void
```

Asserts that a request matching the class name, URL pattern or closure was sent.
The closure receives the request and its response, so it can assert on query
parameters, headers or the payload that came back.

```php
Steam::assertSent(
    fn (GetPlayerBansRequest $request): bool => count($request->steamIds) === 2,
);
```

### `assertSentCount()`

```text frame="none"
Steam::assertSentCount(int $count, ?string $requestClass = null): void
```

Asserts how many requests were sent. `requestClass` narrows the count to a single
request; omit it to count everything the fake recorded.

### `assertSentInOrder()`

```text frame="none"
Steam::assertSentInOrder(array<Closure|class-string<Request>|string> $callbacks): void
```

Asserts that these requests were sent, in this order, and nothing else with them.
Saloon falls back to searching the whole history when a position does not match,
so the count is the part it enforces strictly.

## Recorded traffic

Saloon's `MockClient` readers, proxied onto the facade for tests that inspect the
traffic rather than assert on it. See
[Recorded traffic](/laravel-steam-api-sdk/testing#recorded-traffic).

<Aside type="caution" title="Fake first">
Every reader here reads the mock attached by [`fake()`](#fake). Without one there
is no history at all, so they raise `FakeNotInstalledException` rather than
returning an empty one.
</Aside>

### `lastRequest()`

```text frame="none"
Steam::lastRequest(): ?Saloon\Http\Request
```

The last request the fake handled, or `null` when nothing was sent.

### `lastResponse()`

```text frame="none"
Steam::lastResponse(): ?Saloon\Http\Response
```

The last response the fake returned, or `null` when nothing was sent.

### `recorded()`

```text frame="none"
Steam::recorded(): array<Saloon\Http\Response>
```

Every response the fake recorded, in the order they came back. Reach the request
behind one through `$response->getPendingRequest()->getRequest()`.
