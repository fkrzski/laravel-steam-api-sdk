`Steam::fake()` attaches a Saloon [`MockClient`](https://docs.saloon.dev/testing/recording-responses)
to the connector — your tests never hit the real Steam Web API, and assert on what
they sent through the facade itself.

<Aside type="danger" title="Tests only">
`Steam::fake()` throws `FakeOutsideTestsException` unless the application
environment is `testing`. Nothing detaches the mock once it is attached.
</Aside>

## Faking responses

Pass a map of request class → response. `SteamResponse` builds one for every endpoint
the facade wraps, filled from the [DTO factories](#dto-factories):

```php
use Fkrzski\LaravelSteamApiSdk\Facades\Steam;
use Fkrzski\LaravelSteamApiSdk\Testing\Factories\PlayerSummaryFactory;
use Fkrzski\LaravelSteamApiSdk\Testing\SteamResponse;
use Fkrzski\SteamApiSdk\Http\Requests\ISteamUser\GetPlayerSummariesRequest;

Steam::fake([
    GetPlayerSummariesRequest::class => SteamResponse::playerSummaries(
        PlayerSummaryFactory::new()->personaName('Gabe')->online(),
    ),
]);

$summaries = Steam::summaries([$steamId]);
```

Every builder takes as many factories as you want — an empty call fakes an empty
result:

```php
SteamResponse::playerSummaries();                       // no players matched
SteamResponse::friendList($first, $second, $third);     // three friends
```

It sits on the connector, so it covers every call through the facade — helpers,
`pool()` and `send()` alike — and goes away with the request that installed it.

<Aside title="Why a builder per endpoint">
No two endpoints agree on where the collection goes: `GetPlayerBans` puts it at the
top level, `GetFriendList` under `friendslist.friends`, `GetOwnedGames` under
`response.games` beside the `game_count` the SDK reads to decide whether the profile
is public at all. Hand-written envelopes get this wrong quietly.
</Aside>

| Builder | Request |
| --- | --- |
| `SteamResponse::playerSummaries()` | `GetPlayerSummariesRequest` |
| `SteamResponse::playerBans()` | `GetPlayerBansRequest` |
| `SteamResponse::friendList()` | `GetFriendListRequest` |
| `SteamResponse::userGroupList()` | `GetUserGroupListRequest` |
| `SteamResponse::ownedGames()` | `GetOwnedGamesRequest` |
| `SteamResponse::userStats()` | `GetUserStatsForGameRequest` |
| `SteamResponse::playerAchievements()` | `GetPlayerAchievementsRequest` |
| `SteamResponse::vanityUrl()` | `ResolveVanityUrlRequest` |

## DTO factories

Every DTO the facade returns has a factory for the payload Steam sends. `::new()`
gives a complete, realistic record you can narrow:

```php
use Fkrzski\LaravelSteamApiSdk\Testing\Factories\PlayerSummaryFactory;

PlayerSummaryFactory::new()->toArray();   // the raw payload
PlayerSummaryFactory::new()->make();      // the PlayerSummary DTO
```

Reach for `make()` when a test needs the DTO directly — seeding a repository, or
exercising a method that takes a `PlayerSummary` with no HTTP in the picture.

Named states cover the variations worth naming, and compose:

```php
PlayerSummaryFactory::new()->private();                      // hidden profile
PlayerSummaryFactory::new()->online()->inGame('730', 'CS2'); // online, in a game
PlayerBanFactory::new()->vacBanned(2)->communityBanned();
OwnedGameFactory::new()->withAppInfo()->neverPlayed();
PlayerAchievementFactory::new()->locked();
UserStatsFactory::new()->empty();
```

`state()` covers the rest — raw payload keys merged over the defaults:

```php
PlayerSummaryFactory::new()->state(['profileurl' => 'https://example.test/']);
```

The container factories take the item factories:

```php
UserStatsFactory::new()->stats(
    UserStatFactory::new()->name('DBD_KillerSkulls')->value(1200),
);

PlayerAchievementsFactory::new()->achievements(
    PlayerAchievementFactory::new(),
    PlayerAchievementFactory::new()->locked(),
);
```

Available factories: `PlayerSummaryFactory`, `PlayerBanFactory`, `FriendFactory`,
`UserGroupFactory`, `OwnedGameFactory`, `UserStatFactory`,
`UserStatAchievementFactory`, `UserStatsFactory`, `PlayerAchievementFactory` and
`PlayerAchievementsFactory`, all under
`Fkrzski\LaravelSteamApiSdk\Testing\Factories`.

## Faking failures

Which refusal you need depends on the endpoint under test:

| Builder | Raises | On |
| --- | --- | --- |
| `SteamResponse::profileNotPublic()` | `ProfileNotPublicException` | `GetFriendListRequest`, `GetUserGroupListRequest` |
| `SteamResponse::playerServiceNotPublic()` | `ProfileNotPublicException` | `GetOwnedGamesRequest` |
| `SteamResponse::statsRefused()` | `ProfileNotPublicException` | `GetUserStatsForGameRequest` |
| `SteamResponse::statsRefused()` | `StatsUnavailableException` | `GetPlayerAchievementsRequest` |
| `SteamResponse::vanityNotFound()` | `SteamUserNotFoundException` | `ResolveVanityUrlRequest` |
| `SteamResponse::invalidApiKey()` | `InvalidApiKeyException` | any request |
| `SteamResponse::apiKeyMissing()` | `InvalidApiKeyException` | any request |

<Tabs syncKey="php-test-runner">
  <TabItem label="Pest">
    ```php
    use Fkrzski\SteamApiSdk\Exceptions\ProfileNotPublicException;

    it('surfaces a private friend list', function (): void {
        Steam::fake([
            GetFriendListRequest::class => SteamResponse::profileNotPublic(),
        ]);

        Steam::friends($steamId);
    })->throws(ProfileNotPublicException::class);
    ```
  </TabItem>
  <TabItem label="PHPUnit">
    ```php
    use Fkrzski\SteamApiSdk\Exceptions\ProfileNotPublicException;

    Steam::fake([
        GetFriendListRequest::class => SteamResponse::profileNotPublic(),
    ]);

    $this->expectException(ProfileNotPublicException::class);

    Steam::friends($steamId);
    ```
  </TabItem>
</Tabs>

Three shapes because Steam genuinely answers three ways: `profileNotPublic()` is a
`401`, `playerServiceNotPublic()` a **`200`** whose only tell is the missing key the
endpoint reads — `game_count` for `ownedGames()` — and `statsRefused()` a `400` with
an empty JSON object, which the two ISteamUserStats endpoints read as different
exceptions, because the cause is ambiguous and the SDK does not guess.

<Aside type="caution" title="Two failures cannot be faked with a response">
Neither comes from one: `SteamRateLimitException` is raised by the rate-limit
plugin before a response exists, and `TooManySteamIdsException` by the request
constructor when you pass more than 100 IDs.
</Aside>

## A key is still required

`Steam::fake()` builds the connector before swapping its HTTP client, so the suite
needs *some* key or it hits
[`SteamApiKeyMissingException`](/laravel-steam-api-sdk/configuration#the-api-key). No
request leaves your machine, so the value is irrelevant:

```xml title="phpunit.xml" ins={4}
<phpunit>
    <php>
        <env name="APP_ENV" value="testing"/>
        <env name="STEAM_API_KEY" value="testing"/>
    </php>
</phpunit>
```

## Asserting

Saloon's assertions are proxied onto the facade, so nothing has to hold the mock:

```php
Steam::assertSent(GetPlayerSummariesRequest::class);
Steam::assertNotSent(GetPlayerBansRequest::class);
Steam::assertSentCount(1);
Steam::assertSentCount(1, GetPlayerSummariesRequest::class);
Steam::assertNothingSent();

Steam::assertSentInOrder([
    ResolveVanityUrlRequest::class,
    GetPlayerSummariesRequest::class,
]);
```

`assertSent()` and `assertNotSent()` also take a closure — assert on the request's
query parameters, body or headers when the class alone isn't enough:

```php
Steam::assertSent(
    fn (GetPlayerBansRequest $request): bool => $request->steamIds === $ids,
);
```

<Aside type="caution" title="Fake first">
Each assertion reads the mock `Steam::fake()` attached. Calling one without a fake
raises `FakeNotInstalledException` rather than passing on an empty history.
</Aside>

Saloon's `assertSentJson()` is deprecated upstream, so the facade does not proxy it
— call it on the mock if a test still needs it.

## Recorded traffic

When an assertion isn't the shape you want, the mock's readers sit on the facade
too — the recorded responses, and the last exchange:

<Tabs syncKey="php-test-runner">
  <TabItem label="Pest">
    ```php
    Steam::fake([/* … */]);

    Steam::summaries([$steamId]);

    expect(Steam::recorded())->toHaveCount(1)
        ->and(Steam::lastRequest())->toBeInstanceOf(GetPlayerSummariesRequest::class)
        ->and(Steam::lastResponse()?->json('response.players'))->toHaveCount(1);
    ```
  </TabItem>
  <TabItem label="PHPUnit">
    ```php
    Steam::fake([/* … */]);

    Steam::summaries([$steamId]);

    $this->assertCount(1, Steam::recorded());
    $this->assertInstanceOf(GetPlayerSummariesRequest::class, Steam::lastRequest());
    ```
  </TabItem>
</Tabs>

`recorded()` returns the Saloon `Response` objects in the order they came back.
Both `lastRequest()` and `lastResponse()` return `null` when nothing was sent —
an empty history is not a failure here, that is what `assertNothingSent()` is for.

<Aside type="caution" title="Fake first">
Reading the traffic without a fake raises `FakeNotInstalledException`, same as the
assertions. There is no history to read, and an empty one would say the opposite.
</Aside>

## A complete example

<Tabs syncKey="php-test-runner">
  <TabItem label="Pest">
    ```php title="tests/Feature/PlayerSummariesTest.php"
    use Fkrzski\LaravelSteamApiSdk\Facades\Steam;
    use Fkrzski\LaravelSteamApiSdk\Testing\Factories\PlayerSummaryFactory;
    use Fkrzski\LaravelSteamApiSdk\Testing\SteamResponse;
    use Fkrzski\SteamApiSdk\Http\Requests\ISteamUser\GetPlayerSummariesRequest;
    use Fkrzski\SteamApiSdk\ValueObjects\SteamId;

    it('fetches player summaries', function (): void {
        Steam::fake([
            GetPlayerSummariesRequest::class => SteamResponse::playerSummaries(
                PlayerSummaryFactory::new()->personaName('Gabe'),
            ),
        ]);

        $summaries = Steam::summaries([SteamId::fromSteamId64('76561198000000000')]);

        expect($summaries[0]->personaName)->toBe('Gabe');

        Steam::assertSent(GetPlayerSummariesRequest::class);
    });
    ```
  </TabItem>
  <TabItem label="PHPUnit">
    ```php title="tests/Feature/PlayerSummariesTest.php"
    use Fkrzski\LaravelSteamApiSdk\Facades\Steam;
    use Fkrzski\LaravelSteamApiSdk\Testing\Factories\PlayerSummaryFactory;
    use Fkrzski\LaravelSteamApiSdk\Testing\SteamResponse;
    use Fkrzski\SteamApiSdk\Http\Requests\ISteamUser\GetPlayerSummariesRequest;
    use Fkrzski\SteamApiSdk\ValueObjects\SteamId;

    final class PlayerSummariesTest extends TestCase
    {
        public function test_it_fetches_player_summaries(): void
        {
            Steam::fake([
                GetPlayerSummariesRequest::class => SteamResponse::playerSummaries(
                    PlayerSummaryFactory::new()->personaName('Gabe'),
                ),
            ]);

            $summaries = Steam::summaries([SteamId::fromSteamId64('76561198000000000')]);

            $this->assertSame('Gabe', $summaries[0]->personaName);

            Steam::assertSent(GetPlayerSummariesRequest::class);
        }
    }
    ```
  </TabItem>
</Tabs>
